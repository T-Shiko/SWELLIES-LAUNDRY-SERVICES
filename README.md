# Swellies Laundry Services Website

## Project Overview
Swellies Laundry Services is a local business offering affordable, reliable, and convenient laundry solutions for families, students, and small businesses in Swellendam.  
This website was created to improve the business’s online presence, provide information about services, and allow customers to make enquiries easily.

---

## Sitemap
- **index.html** → Homepage with logo, tagline, image, and “Book Now” button  
- **about.html** → Company history, mission, and vision  
- **services.html** → List of laundry services with images  
- **enquiry.html** → Booking form for laundry services  
- **contact.html** → Contact details and optional form
