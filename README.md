# Swellies Laundry Services Website

## Project Overview

Swellies Laundry Services is a laundry business concept based in Swellendam, Western Cape, South Africa.

The website is designed for families, students, working professionals, and small businesses looking for convenient laundry solutions.

## Website Objectives

- Create a professional and user-friendly website.
- Provide information about the business and its services.
- Allow visitors to search and filter laundry services.
- Provide an interactive image gallery and frequently asked questions.
- Allow visitors to prepare laundry enquiries and contact emails.
- Improve accessibility, responsiveness, and search engine optimisation (SEO).

## Technologies Used

- **HTML5:** Website structure and content.
- **CSS3:** Styling, layouts, animations, and responsive design.
- **JavaScript:** Form validation, search and filtering, FAQ accordion, image lightbox, and DOM manipulation.
- **Visual Studio Code:** Code editor.
- **Live Server:** Local website testing.
- **Git and GitHub:** Version control and project management.
- **Google Maps:** Embedded interactive map showing Swellendam.

## Website Features

### 1. Responsive Design

The website uses CSS media queries, flexible layouts, and responsive elements to support desktop, tablet, and mobile screen sizes.

### 2. Service Search and Filtering

Visitors can search for laundry services using keywords and filter services by category.

The available categories include:

- All Services
- Cleaning
- Finishing
- Delivery

JavaScript dynamically shows or hides service cards based on the selected filter or search term.

### 3. Interactive Image Lightbox

Visitors can click service images to view larger versions.

The lightbox supports closing through the close button, Escape key, or dark background.

### 4. FAQ Accordion

The Services page includes a Frequently Asked Questions section.

JavaScript allows visitors to expand or collapse answers without reloading the page.

### 5. Enquiry Form

The Enquiry page allows visitors to enter their contact details, select a service, choose a preferred date, and provide additional information.

JavaScript validates the form and displays a personalised summary of the enquiry.


### 6. Contact Form

The Contact page allows visitors to enter their name, email address, message type, and message.

JavaScript validates the information and prepares an email using a `mailto:` link.

**Limitation:** The visitor must use their email application to send the message. The website does not automatically send emails.

### 7. Interactive Map

An embedded Google Map displays Swellendam, Western Cape.

Visitors can interact with the map by zooming and moving around it.

The map represents the proposed service area rather than an actual business premises.

## How to Run the Website

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if necessary.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. Use the navigation menu to explore the website.

An internet connection is required to display the embedded Google Map.
